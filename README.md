# Dogs In Water (diw-site)

Static site for dogsinwater.com, served as a Cloudflare Worker (static assets). Same setup as dyd-site / nfdl-site.

## Deploy (its own GitHub + Cloudflare accounts, so it can be sold complete)
1. GitHub Desktop signed in as the `dogsinwater` account → clone the repo → copy everything from this folder into it → commit → push.
2. Cloudflare (dogsinwater account) → Workers & Pages → Create → Import from GitHub → this repo.
   Build command: *(leave empty)*. Deploy command: `npx wrangler deploy` (default). `public/` is already built.
3. Add dogsinwater.com to Cloudflare, switch nameservers at the registrar, delete the old A/AAAA/CNAME records,
   then Workers → diw-site → Settings → Domains & Routes → add `dogsinwater.com` and `www.dogsinwater.com`.
4. Cloudflare Email Routing: forward `hello@dogsinwater.com` (the contact address on the site) to dogsinwaterwebsite@gmail.com.

## Editing
- Site settings, topics and the Amazon tag (`dogsinwater-20`): `site.json`.
- Guides: `content/guides/*.md` with `pillar:` set to a topic slug. Amazon links: `[text](amzn:search words)`.
- Gear page: `content/picks.json`.
- Photos: `content/images.json` (free-license Unsplash IDs + alt text); `python3 scripts/get_images.py` downloads and resizes them.
- Rebuild: `python3 scripts/build.py` (needs `pip install markdown pillow`), then commit `public/`.

## Redirects
All 110 old WordPress URLs (84 posts, shop pages, account pages) 301 to the closest new page.
Generated by `scripts/make_redirects.py` into `redirects.txt`, copied to `public/_redirects` on build.
